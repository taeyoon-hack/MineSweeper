# 💣 지뢰찾기

윈도우 95 감성의 픽셀 스타일로 즐기는 클래식 지뢰찾기입니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

초급(9×9, 지뢰 10개), 중급(16×16, 지뢰 40개), 고급(30×16, 지뢰 99개) 중 난이도를 선택해 플레이합니다. 칸을 클릭해 열고, 마우스 오른쪽 버튼으로 지뢰가 의심되는 칸에 깃발을 표시하세요. 숫자는 주변 8칸에 있는 지뢰 수를 알려주며, 주변에 지뢰가 없는 칸을 열면 안전한 인접 영역도 이어서 열립니다.

첫 클릭한 칸과 주변 8칸에는 지뢰가 놓이지 않아 빈 칸에서 안전하게 시작할 수 있습니다. 지뢰가 없는 칸을 모두 열면 승리하고, 지뢰를 클릭하면 패배합니다. 첫 클릭부터 시작되는 타이머, 깃발 수에 따라 음수도 표시하는 남은 지뢰 수, 난이도별 최고 기록, 8비트 효과음과 음소거 기능을 제공합니다.

## 어떻게 만들었나요

먼저 게임의 목표와 규칙, 화면 구성, 효과음, 기록 저장 방식 및 이번 범위에서 제외할 기능을 PRD로 정리했습니다. 그 내용을 바탕으로 구현 계획을 확인한 뒤, 계획에 따라 HTML·CSS·JavaScript로 게임을 만들고 브라우저에서 동작을 점검했습니다. 이후 PRD에서 빠지기 쉬운 재시작 버튼의 픽셀 표정 상태도 보완했습니다.

## freeform 버전과 비교했을 때

두 버전 모두 난이도 선택, 보드 조작, 타이머와 최고 기록을 갖춘 지뢰찾기입니다. freeform 버전은 구현을 진행하며 기능을 확장했고, PRD 버전은 미리 정한 요구사항을 기준으로 첫 클릭 주변 8칸 안전 규칙, Windows 95 스타일의 입체 베젤, 7세그먼트 표시, 상태별 픽셀 스마일, 효과음과 음소거 동작까지 구체적으로 반영했습니다.

이번에는 요구사항을 항목별로 확인하고 누락된 동작을 보완하기 쉬운 PRD 버전을 선택했습니다. 특히 첫 클릭 안전 범위와 게임 상태별 재시작 표정처럼 세부 동작까지 계획과 대조할 수 있었습니다.

## 실행 방법

별도 설치나 빌드 과정 없이 저장소의 `index.html`을 브라우저에서 열면 실행됩니다. `style.css`와 `script.js`는 HTML에서 자동으로 불러옵니다. 최고 기록은 현재 브라우저의 `localStorage`에 저장됩니다.

## 커스터마이징한 부분

- 초급·중급·고급의 보드 크기와 지뢰 수를 선택할 수 있도록 했습니다.
- 첫 클릭한 칸뿐 아니라 주변 8칸도 안전하게 보장하고, 빈 영역을 자동으로 확장합니다.
- Windows 95 스타일의 입체 베젤, 픽셀 느낌의 숫자 표시와 상태별 재시작 아이콘을 적용했습니다.
- 난이도별 최고 기록 저장, 8비트 효과음 생성 및 음소거 기능을 추가했습니다.
- 커스텀 난이도, 계정·서버 기반 글로벌 리더보드, 멀티플레이어는 구현 범위에서 제외했습니다.
